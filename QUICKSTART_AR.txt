V-PUFT Research Framework v1.0.1 — بدء سريع على Windows
=======================================================

1) فك ضغط المشروع وافتح PowerShell داخل المجلد.

2) إنشاء البيئة وتثبيت المشروع:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -e ".[all]"

3) تشغيل الاختبارات:
   pytest -ra

4) تجربة المشروع دون SUMO:
   vpuft demo --config configs/demo.json --output-dir results/demo

5) تثبيت SUMO:
   winget install --name sumo

6) أغلق PowerShell وافتحه مجدداً، ثم:
   sumo --version
   netconvert --version
   vpuft doctor --config configs/sumo_smoke.json

7) تجهيز وتشغيل سيناريو SUMO الأول:
   vpuft prepare-sumo --config configs/sumo_smoke.json --force
   vpuft sumo-trace --config configs/sumo_smoke.json --scenario-dir sumo/smoke --seed 1001 --output-dir results/sumo_seed_1001

8) تشغيل النماذج الثلاثة على الـTrace نفسه:
   vpuft replay --config configs/sumo_smoke.json --trace results/sumo_seed_1001/shared_detection_trace.jsonl --output-dir results/sumo_seed_1001_models

9) حملة أولية بعشر Seeds مع تحليل الحساسية:
   vpuft sumo-campaign --config configs/full_experiment.json --scenario-dir sumo/smoke --output-dir results/sumo_campaign_10 --seeds 1001 1002 1003 1004 1005 1006 1007 1008 1009 1010 --sensitivity --candidates 5000 --bootstrap-repeats 500 --min-recall 0.95 --max-frr 0.05

10) تشغيل الطبولوجيات الأربع بأوزان مشتركة:
   vpuft topology-campaign --config configs/full_experiment.json --scenarios sumo/smoke sumo/corridor sumo/intersection sumo/grid --output-dir results/four_topologies --seeds 1001 1002 1003 1004 1005 1006 1007 1008 1009 1010 --sensitivity --candidates 5000 --bootstrap-repeats 500 --min-recall 0.95 --max-frr 0.05

ملاحظات مهمة:
- results/demo_reference نتائج اصطناعية لا تستخدم في الرسالة.
- لا تعتمد الأوزان النهائية قبل حملة متعددة البذور والطبولوجيات.
- Ahmed-Inspired هو تطبيق معماري مستوحى من المقالة، وليس إعادة تنفيذ حرفية للتوقيع الحلقي العتبي.
- اقرأ README.md وdocs/EXPERIMENT_PROTOCOL.md قبل الحملة النهائية.
