# السيناريو الخامس: Urban Roundabout

هذا السيناريو امتداد مستقل ولا يغيّر ملفات أو نتائج السيناريوهات الأربعة السابقة.

## التصميم الثابت

- طريق محيطي مستطيل ثنائي الاتجاه بسرعة `50 km/h`.
- دوّار حقيقي أحادي الاتجاه مكوّن من ثمانية مقاطع بسرعة `30 km/h`.
- أربعة محاور شعاعية: شمال، شرق، جنوب، غرب.
- أربع إشارات مرور ثابتة عند مداخل الدوّار.
- ست وحدات RSU: أربع قرب المداخل واثنتان على الطريق المحيطي.
- ستة عشر مساراً تغطي العبور والاستدارة والحركة المحيطية.

## مصفوفة التجربة

- المركبات: `20, 40, 60, 80, 100`.
- البذور: `1001..1010`.
- الهجمات: الأنواع السبعة نفسها وبنسبة `35%` موزعة بالتساوي قدر الإمكان.
- الأوزان والسياسات: مجمّدة، ولا توجد إعادة معايرة.
- الحالات المعمارية لكل أثر SUMO مشترك:
  1. `distributed_density_honest`.
  2. `centralized_remote_0ms_control`.
  3. `centralized_remote_100ms`.

عدد آثار SUMO هو `5 × 10 = 50`. عدد التقييمات المعمارية هو `50 × 3 = 150`.

## الصورة المرجعية

الصورة الأساسية تستخدم `60` مركبة والبذرة `1001` عند الثانية `25`، لأنها تعرض جميع المركبات بعد نافذة المغادرة وتُظهر جداول الهجوم وهي فعالة، دون اختراع حالات تصنيف غير متاحة في لقطة الحركة.

```powershell
$env:SUMO_HOME = "C:\Program Files (x86)\Eclipse\Sumo"
python scripts/capture_urban_roundabout_snapshot.py
```

## التشغيل الكامل

```powershell
.\scripts\run_urban_roundabout_campaign.ps1
```

التقرير يخص السيناريو الخامس وحده. المقارنة مع السيناريوهات الأربعة السابقة لا تُجرى إلا عند طلبها صراحة.
