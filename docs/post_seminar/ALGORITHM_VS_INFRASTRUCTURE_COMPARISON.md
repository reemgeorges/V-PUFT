# Algorithm and infrastructure interventions

Phase 4 found 37 FN windows with already eligible supporting evidence recoverable by B8 observer matching, 876 with one in-range RSU, 29 with several observers but no second eligible supporting contribution, and 19 limited by margin or contradiction. B8 had no additional pilot classification gain over the existing B1 and cost more CPU. These are separate mechanisms from moving sensors.

The Phase 5 C1 pilot relocates sensors while retaining B0. It increases two-RSU overlap for some emitted messages but loses first-observer coverage for 460 malicious messages at density 100. The apparent Recall increase there accompanies lower TP and fewer at-risk windows; it is rejected. C2 adds B1 to the same candidate placement and has the same TP in both pilot cells. There is no evidence of a reliable combined improvement. Original policies and attack truth remain intact throughout.
