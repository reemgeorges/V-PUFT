# فهرس أرشيف دراسات ما بعد الندوة

التقارير في هذا المجلد نسخ مطابقة من Git blobs تاريخية. النتائج الملخصة موجودة في research_archive/post_seminar/، ونسخة Dataset A في research_archive/scenario5_dataset_a_report_linked/. يسجل PROVENANCE_INDEX.json commit المصدر وblob SHA-1 وSHA-256 للمصدر والنسخة.

الشيفرات والتكوينات والاختبارات والملفات المصدرية التجريبية محفوظة كنصوص خام معزولة تحت source_snapshots/ والتغييرات تحت source_patches/. لا تُنسخ هذه الملفات إلى src/ ولا تُفعّل في خط الإنتاج. لم تُنسخ SUMO traces الخام ولا نسخ العمل الاحتياطية، وقد تشير manifests إلى مسارات محلية.

أُعيدت كذلك ملفات النتائج الملخصة إلى مساراتها التاريخية تحت results/ حتى تعمل إحالات التقارير؛ توثق قائمة historical_path_mirrors في PROVENANCE_INDEX النسخ المطابقة.
