# Phase 6: fixed attack-opportunity evaluation

An opportunity is a vehicle and fixed 15-second window containing at least one emitted message with `ground_truth_malicious=true` in the original generated-message log. This emission log is independent of RSU detection. An opportunity remains in the denominator when no RSU detects any malicious message. Observed means at least one RSU detection event references one of its malicious message IDs. A detection success means a committed first revocation occurs in that same window; opportunities before it without revocation are misses. Later opportunities after that first revocation are terminal and reported separately, not counted as new TP or FN. False benign-vehicle revocations count committed revocations of vehicles with no emitted malicious message anywhere in the run.

`opportunity_recall` divides first-revocation successes by opportunities before terminal revocation, so it can vary with censoring. For placement comparisons use the fixed-universe fields too: `fixed_universe_first_detection_fraction` and `fixed_universe_protected_fraction` divide by all emitted attack opportunities, the latter including subsequent terminal opportunities. The output also provides the common observed-opportunity and union-of-observed-opportunities comparisons. Historical state-aware window metrics remain unchanged alongside these measures. Ground truth is used only after decisions, for evaluation.

The 1007 pilot opportunity comparison is in `results/post_seminar_phase6/opportunity_pilot_comparison_corrected.csv`; the incorrect earlier output referencing Phase 5 is retained and is not authoritative. The evaluator uses Phase 6 regenerated traces and the Phase 2 baseline decision log.

## Final held-out validation

The final paired evaluation covers seeds 1007–1010 at all five densities (20 cells). It uses a common fixed set of emitted malicious-message opportunities per pair, verifies identical mobility/message/ground-truth hashes, and includes zero-observation opportunities. Full results, terminal counts, confusion totals, common/union case comparisons, exact false-positive cases and paired seed-level statistics are in [PHASE_6_FINAL_HELDOUT_RESULTS.md](PHASE_6_FINAL_HELDOUT_RESULTS.md) and `results/post_seminar_phase6_final/`. The fixed-universe protected fraction is the primary cross-placement measure; active-window opportunity Recall and historical state-aware Recall remain separately named because revocation changes their effective denominators.
